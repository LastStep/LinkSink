## What is different now

LinkSink now has CI/CD on GitHub. Every push and pull request runs Bonsai's check, the whole ladder (types, lint,
624 unit tests, the e2e tests in Chromium, build and size) and builds the app image, starts it behind Caddy and
checks that https://localhost/login answers and plain http redirects. When main is pushed (or a v* tag), and all of
that passed, the same image is published to ghcr.io/laststep/linksink, and a deploy job updates a server over SSH
once the person has set its secrets (until then it skips with a notice). deploy/SERVER.md gives the steps for
running LinkSink on another Docker machine from that image, with no source there: a server with a domain, or a
machine on the home network; moving the links there from this computer; updating; and the deploy secrets. The local
certificate's warning can now always be clicked past: HSTS is sent only for names with a public certificate.

## Deviations from the plan

- **bonsai check is a job in ci.yml, not its own `.github/workflows/bonsai.yml`** (base:ci's file name), so one run
  carries every check and publish can wait for it. Its steps are base:ci's, with the "from Bonsai 1.0" download.
- **CI climbs rung 0 too** (`bonsai ladder --ci` runs every rung bonsai.yaml defines; rung 0, the guard, is green
  with no task). The done_when names rungs 1 to 5.
- **A sixth secret, `DEPLOY_KNOWN_HOSTS`** (plus an optional `DEPLOY_PORT`), beside host, user, key and folder: the
  server's host key, so the deploy never trusts whatever answers at that name. With any of the five missing it skips.
- **The Dockerfile's Node base is pinned by digest** (one line), from the task's carried note "pin images by
  digest"; the task's scope names compose.yaml, not the Dockerfile. No app code changed.
- **deploy/README.md's `docker image rm linksink-app` line now names `ghcr.io/laststep/linksink`** (the image's new
  name here), with a note for the older one. Its run commands are unchanged.
- The image is built for linux/amd64 only; SERVER.md says so, and how to run on ARM (from the source).
