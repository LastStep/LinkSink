# Run: T-0028 (app-icon)

> Opened at the start and added to as it goes. One branch (t0022-sidebar-rename-icon) carries T-0022, T-0027, T-0028.

## What is different now

The browser tab shows LinkSink's mark (the sink with its tap, the one top left) instead of Svelte's logo. The tab icon
is black on a light browser theme and white on a dark one. Browsers that do not draw SVG icons use a 32 px PNG (a white
tile with a hairline edge, readable on a light or a dark tab), and a phone's "Add to Home Screen" uses a 180 px
apple-touch-icon (the mark in white on a black square). Every page links all three, the sign-in and sign-up pages
included, because they come from the root layout.

## Deviations from the brief

- The SVG moved from `src/lib/assets/favicon.svg` to `static/favicon.svg`, linked as `/favicon.svg`: as an imported
  asset, Vite turned the small file into a `data:` URI inside the page's JavaScript, which is a poorer icon link and
  costs bytes in the first load. The old file is gone (`git mv`).
## Deviations from the brief

  (SIGTERM was ignored by the e2e server), which held the shared Playwright lock for about 35 minutes and blocked the
  other builders. I stopped both (pids 802857 and 802864, both started by me); the script now kills with SIGKILL.
